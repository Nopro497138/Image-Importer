# Image Importer

Import any image into your Geometry Dash level!

## Features
- Import PNG, JPG, JPEG, and BMP images
- Three quality levels: Low, Medium, High
- Live preview of selected image
- Automatic pixel art conversion

## Usage
1. Open the editor
2. Click the "Image Import" button (top right)
3. Select your image
4. Choose detail level
5. Click "Import"
